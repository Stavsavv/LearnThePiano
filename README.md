# Keynova – Piano Trainer
Piano-trainer's engine (MIDI, graded Learn/Perform modes, notation, scoring) with Keynova's look, home page, courses, tutorials and results screen.
Open keynova.html in Chrome or Edge (Web MIDI needs one of them). No build, no backend; progress is saved in localStorage (export/import under Progress).
Tests: node tests/engine.test.js keynova.html && node tests/notation.test.js keynova.html
